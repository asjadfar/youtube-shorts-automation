# Short — Voiceover Script

> Complete voiceover for one Short (4-6 scenes, 60 seconds or less).
> One speaker per line. Short, simple Urdu lines.
> Record / generate this audio separately and lay it over the stitched video —
> it is never part of the visual prompts.
> A 2-second pause goes before each answer, so the child can guess.
>
> LANGUAGE: Urdu by default. Write each line in Urdu script (for TTS) with
> Roman Urdu in brackets (so the owner can read it). If the owner wants this
> Short in English instead, translate the same lines — do not write a different script.

## Worked example — "Count 1 to 4 with Bunny" (6 lines, 60 seconds)

1. **Bunny:** "ہیلو! میں بنی ہوں! آؤ گنیں!" (Hello! Main Bunny hoon! Aao ginein!)
2. **Bunny:** "کتنی بطخیں؟ ایک! ایک بطخ!" (Kitni batkhein? Ek! Ek batkh!)
3. **Bunny:** "کتنے سیب؟ ایک، دو! دو سیب!" (Kitne saib? Ek, do! Do saib!)
4. **Bunny:** "کتنے پھول؟ ایک، دو، تین! تین پھول!" (Kitne phool? Ek, do, teen! Teen phool!)
5. **Bunny:** "کتنے غبارے؟ ایک، دو، تین، چار! چار غبارے!" (Kitne ghubaray? Ek, do, teen, chaar! Chaar ghubaray!)
6. **Bunny:** "بہت اچھا! سبسکرائب کریں!" (Bohat acha! Subscribe karein!)

## Worked example — Format B, "Cow, Lion, Duck — What Sound?" (5 lines, 50 seconds)

1. **Bunny:** "یہ کس کی آواز ہے؟ آؤ اندازہ لگائیں!" (Yeh kis ki awaaz hai? Aao andaza lagayein!)
2. **Bunny:** "گائے کہتی ہے… مو!" (Gaaye kehti hai… Moo!)
3. **Bunny:** "شیر کہتا ہے… غرا!" (Sher kehta hai… Roar!)
4. **Bunny:** "بطخ کہتی ہے… کوئیک!" (Batkh kehti hai… Quack!)
5. **Bunny:** "سب کا اندازہ درست! سبسکرائب کریں!" (Sab ka andaza durust! Subscribe karein!)

## Voiceover notes

- Voice: one warm, friendly adult voice for Bunny; if a Narrator line is needed, one calm adult voice — never two voices on the same line.
- Pace: slow and clear, one number per beat, so a small child can count along.
- Keep every line short and simple. One question and one answer per line at most. A line a small child cannot follow is too long — cut it.
- If lip-sync is attempted, sync only the speaking character and only on their own line. If it misattributes, fall back to plain voiceover with no lip-sync.
