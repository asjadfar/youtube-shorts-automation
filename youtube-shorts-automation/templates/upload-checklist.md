## Video check

- [ ] Video is 9:16 portrait vertical, 720x1280, verified with ffprobe: width 720, height 1280
- [ ] Total length 60 seconds or less (4-6 scenes, in script order) — over 60 seconds is NOT a Short
- [ ] All 4-6 scenes present, in the right order, no scene missing or duplicated
- [ ] Hook shows Bunny's face and the question in the first 3 seconds
- [ ] 2-second pause before each answer is present
- [ ] Finale loops cleanly back to the hook and includes the subscribe call
- [ ] Audio / voiceover matches the script, one speaker per line
- [ ] No burned-in text (except the single numeral/letter for the scene), no dialogue bubble, no off-model character in any scene
- [ ] Watched the finished video start to finish (not just the first seconds)

## Title / description / hashtags

- **Title (exact text):**
- [ ] Title is under 100 characters, lesson matches the Short's lesson
- [ ] #Shorts is in the title or in the description (one of the two, always)
- **Description (exact text):**
- [ ] Description is short (2-3 lines + hashtags), learning goal in the first two lines
- **Hashtags (exact list, 3–5 only, always including #Shorts):**
- [ ] No more than 5 hashtags, all relevant

## Thumbnail

- **Thumbnail file (exact path):**
- [ ] Size 720x1280 portrait
- [ ] Bunny host + one item, readable at phone size
- [ ] At most 4 words of text on the thumbnail, large and high contrast
- [ ] Same storybook style as the video, no burned-in dialogue
